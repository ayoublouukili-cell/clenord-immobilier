# Clénord Immobilier

Static, multilingual real estate website for Tanger. Includes a property gallery, immersive imagery and interactive 360° district models.

## Local preview

Run `npm.cmd start` on Windows, then open http://127.0.0.1:8000.

No dependency installation is required. Run `npm.cmd run build` to validate JavaScript and local asset references, and `npm.cmd test` for animation and camera checks.

## GitHub Pages

Push this project to the repository's `main` branch. In **Settings → Pages → Build and deployment**, select **GitHub Actions** as the source. The included workflow checks the project and publishes `dist/`. The successful **Publish Clenord website** workflow exposes the public website URL.

Images and property listings are illustrative. The 3D districts are fictional demonstrations.
